# Design Context

### Users
Primarily recruiters/hiring managers browsing the portfolio (quick, skimmable — this page shows personality behind the UX work), but also occasionally shared as a direct personal link, where it should read more like an intimate, nostalgic diary.

### Brand Personality
Editorial / refined, confident & minimal. Restrained, magazine-like, lets content speak — not corporate, not decorative for its own sake. The doodle-journal page specifically carries a warmer, personal-sketchbook register (paper/ink palette, handwritten warmth) layered on top of the site's editorial base.

### Aesthetic Direction
Site-wide: Source Serif 4 (serif) + Source Sans 3 (sans) — see `style.css :root`. Playfair Display + DM Sans is a local override used only on the Driver App case study, not a site-wide pairing.
Doodle-journal page: local paper/ink theme (`--brand: #b85b3c`, `--paper`, `--ink` tokens defined in-page) evoking a physical notebook/diary. Keep this page's palette scoped to its existing tokens — don't introduce new colors.

### Design Principles
1. Editorial restraint — hierarchy through size/weight/color, not decoration.
2. Changes to work/doodle-journal/index.html should stay scoped to that file; don't touch shared style.css/case-study.css typography rules.
3. Preserve the warm, handwritten-diary feel already established (serif italic subtitles, mono captions) when refining type.
4. Body text readable at a glance for skimming recruiters, but comfortable for slower, closer reading too.
